Scientific Calculator

About the Project

A scientific calculator developed using web technologies to perform basic arithmetic and scientific calculations.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- Addition, subtraction, multiplication and division
- Sine (sin) and cosine (cos)
- Other scientific operations
- User-friendly interface

How to Run

1. Download the project ZIP file.
2. Extract the files.
3. Open "index.html" in a web browser.
